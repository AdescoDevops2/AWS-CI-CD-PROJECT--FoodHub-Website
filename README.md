# AWS CI/CD-PROJECT -FoodHub-Website
Food hub is a simple food delivery website developed as an AWS CI/CD  hands-on project.

TECHNOLOGIES:
-HTML
-CSS
-JAVASCRIPT
-GIT

FEATURES:
-Food Menu.
-Food Ordering Button
-Shopping Cart Simulation
-Responsive Design
-Restaurant Information.

AWS PROJECT
This project demonstrates how to:
1. create an AWS codecommit repository
2. configure GIT.
3. clone a respository
4. commit changes
5. push source code
6. create branches
7. merge branches
